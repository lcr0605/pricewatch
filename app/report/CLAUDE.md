# 보고서·알림 규칙
- 유료 API(LLM 등) 금지. 문장은 `daily.py`의 템플릿으로만 만든다
- 숫자는 `analysis.rules`가 만든 Event 값만 사용. 여기서 새로 계산하지 않음
- 판정 기준·중요도 점수는 `app/analysis/rules.py` 상단 상수에서만 변경
- 즉시 알림: target_reached, big_drop, big_rise (INSTANT_KINDS). 나머지는 일일 보고서에만
- 목표가 알림은 처음 도달한 날만 (반복 알림 금지)
- 첫 수집일(비교 대상 없음)은 "변동 없음"이 아니라 "비교 불가"로 표기
- 텔레그램 4096자 제한 → `fit()`으로 자름. 섹션당 최대 10줄
- 토큰이 없으면 전송하지 않고 출력만 (수집은 계속 진행)
- 보낸 즉시 알림·점검 알림은 `alerts` 테이블에 기록
