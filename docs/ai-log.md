# AI(Claude Code) 활용 기록

Claude Code로 개발하면서 AI에게 맡긴 작업과, 결과를 검토해 직접 고친 부분을 기록합니다.

## 2주차 · 가격 변동 분석 + 일일 보고서
- **맡긴 작업:** 오늘/직전 가격 비교 SQL, 판정 규칙(급변·목표가·30일 최저·판매처 급감·가격 갭), 텔레그램 보고서 템플릿
- **요구사항으로 준 조건:** 유료 API 금지, 숫자는 코드가 계산, 목표가 알림은 처음 도달한 날만, 텔레그램 길이 제한 대응
- **검토하며 고친 점**
  1. **첫 수집일 문구 오류:** 실제 DB로 보고서를 만들어 보니, 비교할 어제 데이터가 없는데 "40개 모두 가격 변동이 없습니다"라고 출력됨 → 담당자가 오해할 수 있어 "첫 수집일이라 비교 불가"로 구분 (`compared` 인자 추가, 테스트 추가)
  2. **테스트 기대값 오류:** 길이 제한 테스트가 실제 출력 문구(`… (이하 대시보드에서 확인)`)와 다른 문자열을 기대해 실패 → 기대값 수정
- **결과:** 테스트 33개 통과, 실제 DB 데이터로 보고서 출력 확인
