# 수집 정책

## 확인한 내용 (2026-10-21)
- **robots.txt**: 검색(`search.danawa.com`)·상품 상세(`prod.danawa.com/info/`) 페이지는 허용. `/api/`, `/bridge/`, `/info/ajax/`, `/list/ajax/`, `/community/`는 금지
- **이용약관**: 자동 수집을 직접 금지하는 조항은 없음. 제24조에서 회사 정보를 사전 승낙 없이 복제·배포해 **영리 목적**으로 이용하는 것을 금지. 하단 안내에서 콘텐츠 무단 복제·가공을 금지
- **기술적 차단**: 연속 요청에도 캡차·차단 없음 (쿠팡은 첫 요청부터 403으로 차단되어 제외)

## 운영 원칙
1. 비영리 포트폴리오 용도로만 사용
2. 하루 1회, 상품 50개 이하, 요청 간 3~5초
3. robots.txt 금지 경로와 기술적 차단 우회는 하지 않음
4. 수집 데이터는 저장소에 올리지 않고, 대시보드는 로그인한 사람만 열람
   - 예외: README 소개용 대시보드 스크린샷(`docs/images/`) 몇 장. 화면에 보이는 상품 일부의 하루치 가격만 담기고, 원본 데이터(DB 내용)는 올리지 않음
5. 상품 상세 페이지의 검색엔진용 구조화 데이터(JSON-LD)를 우선 사용 → 화면 구조 변화에 덜 민감
